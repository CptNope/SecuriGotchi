Installation & integrations
Data-directory moves, HTTP binding, HTTPS cookie mode, MCP enablement, GPG keys, optional dependency installation and OS service setup remain terminal-managed. These settings require filesystem/OS setup or a process restart; they cannot be safely applied as ordinary dashboard preferences.
